# AIRepo — SO-01 Framework Charter and Scope

## Mission
Provide a reusable, technology-agnostic and provider-neutral framework for organizing engineering assets in repositories and for constraining repository-facing AI-agent behavior so that authority, ownership, provenance, discoverability, lifecycle and compatibility remain explicit.

## Authority boundary
AIRepo is an assessment/design framework and does not become part of a target project's authority hierarchy merely by being applied. The target project's accepted authority chain always wins on project decisions.
