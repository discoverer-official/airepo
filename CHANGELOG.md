# Changelog

All notable public changes to AIRepo are documented here. Public Semantic Versioning starts at `1.0.0`; earlier AIROF-labelled revisions were private/pre-public development and validation identities, not public predecessor releases.

## [1.1.0] — 2026-08-19

Backward-compatible minor release derived from frozen AIROF v3.1.0.

### Added

- `VAL-003 — Evidence fitness for claim`;
- claim-relative evidence observability/fitness and explicit insufficient-evidence behavior;
- routine Class A/B Fast Path for low-risk work.

### Simplified / clarified

- `EXEC-001` is explicitly scoped to AIRepo assessment/adoption/remediation execution;
- Machine Projection and localization remain supported public distribution projections but are no longer default Framework qualification burdens;
- public-distribution mechanics are kept out of reusable Core beyond generic derived-release semantics;
- evidence reuse remains claim-relative and does not inherit PASS across changed subjects.

### Compatibility

- all 28 active Rule IDs from AIRepo 1.0.0 remain active and compatible;
- one new active Rule ID (`VAL-003`) brings the active total to 29;
- `EVAL-001` remains reserved and is not reused;
- direct public rollback parent is AIRepo 1.0.0.

## [1.0.0] — 2026-08-15

First public stable release of **AIRepo — The AI-Ready Repository Framework**.

### Included

- ten canonical semantic owners (`SO-01`…`SO-10`);
- stable normative Rule IDs and applicability semantics;
- repository assessment and bounded design method;
- AI-agent execution constraints;
- migration, compatibility, validation, conformance, and release governance;
- deterministic machine-readable projection and schema;
- revision-bound EN/RU localization subset;
- pre-public qualification and two-consumer validation provenance.

### Public identity

This release establishes the `AIRepo` public name and `1.0.0` as the beginning of the public version lineage.
