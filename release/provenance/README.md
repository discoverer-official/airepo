# Pre-public provenance

AIRepo 1.0.0 is the first public release. The framework was developed and validated before public naming under the internal identifier **AIROF**.

The evidence files in this directory are intentionally retained with their original internal terminology and revision identities. They are historical validation/qualification evidence, not current semantic authority and not public predecessor releases.

Current AIRepo semantics are owned only by `../../framework/SO-01.md` through `../../framework/SO-10.md`. The current release identity and exact source hashes are defined by `../manifest.md`.
