# AIRepo release provenance

AIRepo public releases are immutable distribution snapshots derived from the accepted AIROF working/evolving engineering lineage.

Evidence files in this directory intentionally retain their original AIROF terminology and exact identities. They are historical validation/qualification/freeze evidence, not current semantic authority and not public consumer API.

AIRepo 1.1.0 derives from frozen source release `AIROF-v3.1.0-f5e726a1b8a22e18`, which was frozen from exact qualified candidate `AIROF-REV-2cb61537e0c025ef` after independent assurance and explicit Human Approval.

Current AIRepo semantics are owned only by `../../framework/SO-01.md` through `../../framework/SO-10.md`. The public release identity and exact source hashes are defined by `../manifest.md`.

Existing 1.0.0 provenance files are retained unchanged.
